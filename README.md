# Jeush Daniel Peraren — Personal Portfolio

A responsive blue-and-white student portfolio for Jeush Daniel Peraren, a second-year college student at Kabankalan Catholic College.

## Assignment folder

The source is prepared for the required folder name `peraren-project-1`. If your teacher expects the files to be nested inside that exact folder, rename the outer folder from `perarenpf` to `peraren-project-1` before submitting or pushing it.

## Files

- `index.html` — main portfolio page
- `styles/main.css` — responsive styles
- `assets/avatar-mark.svg` — profile monogram asset
- `404.html` — GitHub Pages fallback for missing routes
- `manus-routes.json` — page route manifest

## Run locally

Because this is a static site, you can open `index.html` directly in a browser. For a local server, run:

```bash
python3 -m http.server 3000
```

Then visit `http://localhost:3000`.

## Personalize before submission

Replace the placeholder email, GitHub, and LinkedIn links in `index.html` with your real links. Add real project entries as you complete more work. The site currently uses only blue and white so it can be personalized later without changing the page structure.

## GitHub Pages

Push the project to a GitHub repository, then open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save. GitHub Pages will publish `index.html`.

## Submission check

Before submitting, confirm that the repository is public, the `main` branch contains at least 10 meaningful commits, the Pages URL opens successfully, and both the repository URL and published Pages URL are ready for the class form.
